# wscyber

公司内部、明确授权的 Web/API 安全研究平台，基于 [Cyber Harness](https://github.com/chainreactors/cyber-harness) 扩展：给出目标与授权范围，Agent 自主探索，平台保存真实 HTTP 证据，形成候选漏洞并独立验证、出报告、复测。

- 架构与代码地图：[docs/architecture.md](docs/architecture.md)
- 构建与运行：[native/RUNNING.md](native/RUNNING.md)
- 当前进度：[docs/STATUS.md](docs/STATUS.md)
- 开发规范：[AGENTS.md](AGENTS.md)

仅用于自有或获授权的系统与本地靶场。
