# 产品需求与功能清单

本文件是用户需求的唯一汇总：做什么、为什么、做到什么程度算完成。实现细节看 [architecture](architecture.md)，进度看 [STATUS](STATUS.md)。旧需求原文可在 tag `legacy-snapshot` 的 `docs/product-confirmation.md`、`findings-and-reporting.md`、`research-configuration.md`、`task-interaction-backlog.md` 查阅。

## 1. 用户要什么

一个**内部渗透自动化平台**：像用 Cyber 一样，给出目标就让 Agent 自己去测；人主要看它**做了什么、发了哪些包、找到什么、证据是否站得住**，然后出报告、做复测。

用户最在意的不是视觉花样，而是这些细节是否好读、好查：**Agent 执行输出与日志、工具结果、HTTP 请求/响应、漏洞结论与报告**。

首版场景：**Web/API 漏洞挖掘**。代码审计、CTF、内部演练是长期方向，首版不做。

**长期目标（2026-11-17 用户提出）：企业内部自动化渗透 Harness。** 固定资产（测试环境）登记一次，按月/季度自动下发渗透任务，不再靠人逐个测；经独立验证的漏洞自动登记到内部 SDL 平台并推送企业微信，推送内容只含精简描述、关键复现步骤和 HTTP 原件截图（类 BP 界面）；平台保留完整记录与可追查日志；Agent 执行删除数据、删除用户、高危命令等危险操作前被审批拦截；连接器和能力可扩展。分阶段计划见 [roadmap](roadmap.md)。

## 2. 核心用户链（首版）

1. **建任务**：两个主要输入——“目标／已知信息”“希望达到的目标”——加明确授权 origins，点“开始探索”。不要求用户拆计划。
2. **自主探索**：Agent 自主选择步骤和工具，不逐步审批。过程可实时看到。
3. **流量与证据**：每个真实请求/响应可列表筛选、双栏查看、复制；明确标出截断/未发送/无响应。
4. **候选漏洞**：运行中即可看到新候选（平台编号 `WSC-000001`），正文只有三段：简短描述（原理/危害）、复现步骤（就近关联真实请求/响应）、修复建议。历史修订、时间线按需展开。
5. **独立验证**：对候选的固定修订发起新会话，取得新证据，给出“支持 / 反证 / 证据不足”判读。判读不自动确认漏洞；是否成立、严重度、是否纳入报告分开记录。正常权限/有意开放的功能不能当漏洞。
6. **报告**：基于固定修订和证据生成报告，先 Markdown/JSON，导出 ≠ 发布。缺材料标“未提供”，不编造。
7. **复测**：每个漏洞可单独复测，保留每次独立结论（仍可复现 / 本次范围内已修复 / 无法判定）与新证据，不覆盖原发现。登录失败、不可达 ≠ 已修复。

## 3. 配套功能（首版范围）

| 功能 | 要点 |
|---|---|
| 模型配置 | 多供应商/自定义地址/Header/参数，显式“测试连接”；保存不自动探测 |
| 用量 | 每日、每任务 tokens；费用只在有价格依据时显示“估算” |
| 模型原文记录 | 任务级开关；开启时可查看每轮实际输入/返回；关闭时不旁路保存原文；目标流量始终记录 |
| 资料库 / Skill | 文件夹式资料；标为 Skill 的由 Agent 按需发现/加载，普通资料显式选用；不执行附件脚本 |
| 测试安全 | 可开关的“禁止行为”提示词清单；明确这是软约束，不是拦截 |
| 执行复盘 | 按方向/会话查看系统下发的任务说明、逐次模型与工具交互、产生的证据和候选 |
| 任务内对话 | 在任务里问进展、解释证据、调整方向；只读查询不触发执行，调整要有真实回执 |
| 探索图谱 / 发现时间线 | 基于已保存的真实关联，不由模型编故事 |

Cyber 原生已有的能力（会话、聊天、工具流、模型配置、Skill 等）**优先直接用**，只补平台业务差异。

## 4. 首版不做

公网部署、Repeater/批量重放、PDF 排版。多租户、登录与角色（管理员/普通用户）已于 11-22 提前列入 [roadmap](roadmap.md) 阶段 P（先迁 Postgres）。测试策略开关（范围限制 / 危险操作审批 / 全工具出口，默认开启基础限制，用户可显式关闭）、资产与周期任务、企业微信/SDL 推送已列入 [roadmap](roadmap.md) 阶段 B–D（SDL 需接口文档，无协议不猜）。未实现前不开放假入口。

## 6. 首版验收基准

用固定本地靶场跑一遍完整链：建任务 → 自主探索 → 流量 → 候选 → 真实模型独立验证得出判读 → 报告 → 复测，每步在浏览器可读。以此作为“首版可用”的标准，而不是单个组件或样式通过。
