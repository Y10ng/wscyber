# UI-1 共享组件库与规划覆盖

2026-11-11首轮已完成。视觉规范见 [UI-1](ui-baseline.md)，真实业务能力仍以 [STATUS](STATUS.md) 为准。组件库是实际代码、可点击展示、状态用例与使用约束，不是全产品实现声明。

## 0. 页面开发先查本库（2026-11-12）

本库是正式前端的实现基线，不是可绕过的展示附件。先复用共享组件和已有标准用例，缺少可复用组合先补库/用例/覆盖，再接入业务；外部Ant文档仅用于底层API核对，不能代替项目页面设计。基础控件允许在统一Provider下按已有用例直接使用，这不等于允许每页自定义主题、弹窗或交互。任务包须列具体复用路径和缺项，不得一边禁改共享UI一边要求页面临时重造。

当前六类41项是覆盖条目数，**并非41个全部完成的共享业务组件**。模型配置键值编辑组合尚未独立登记为可复用；仅展示的资料版本/报告版本交互还须按用户最新要求重新审视，不能直接搬入正式产品。当前只做文档整理，未新增组件或重跑本页历史验收。完整规则见[开发规范总览](development-standards.md)。

## 2. 复用方式与职责

```tsx
import { useState } from 'react'
import { Button } from 'antd'
import { UIProvider } from '../ui/UIProvider.tsx'
import { TaskModal } from '../ui/TaskModal.tsx'
import { CopyButton, GridFold } from '../ui/SurfaceControls.tsx'

// 每个独立入口一个Provider；业务草稿和提交状态留在调用层。
function Example() {
  const [open, setOpen] = useState(false)
  return <UIProvider appearance="light">
    <Button onClick={() => setOpen(true)}>打开</Button>
    <TaskModal title="材料" open={open} onCancel={() => setOpen(false)} footer={null}>
      <GridFold title="详细内容"><p>按文本展示的材料</p></GridFold>
      <CopyButton key="record-1" label="复制材料" text="按文本展示的材料" />
    </TaskModal>
  </UIProvider>
}
```

| 共享接口 | 使用约束 |
|---|---|
| `UIProvider` / `surfaceTokens` | 单入口单Provider；主题写入document和Ant portal。颜色/字重以`surface.ts`为唯一来源，不复制主题；不持久保存用户偏好或材料。 |
| 官方Ant基础组件 | 在Provider下直接使用，不机械包装API。字段需关联label；错误定位就近；授权、日期、资料等输入不自行产生执行许可。 |
| `AppShell` | 调用方提供导航、标题、操作、内容；只开放真实能力。`navigationLabel`默认“组件分类”，正式入口传“主导航”。自带可折叠左导航和可滚动内容，不内建路由/业务状态。 |
| `TaskModal` | 居中、视口内滚动与首尾Tab补偿；任务弹窗与遮罩固定无进出场动画，避免动态减少动效下零时长动画阻塞关闭。草稿/提交/关闭语义由调用方负责；串行切换使用`afterClose`，显式设置焦点归还，不可重叠焦点陷阱。 |
| `CopyButton` / `createCopyLifecycle` | 复制成功才显示对勾，失败明确提示，2500ms复位；重复、text变化与卸载使旧完成失效。记录/项目身份变化时用key重新挂载，哪怕文本相同。 |
| `EvidenceBytesViewer` | `sourceKey`标识非敏感记录/材料归属；`base64Value?`、`charset?`、`label`、`filename`由调用方提供。复制只取当前文本/hex/Base64预览，下载完整已保存字节；不调用API、不反编码预览生成附件。缺失/显式空/非法分开。 |
| `GridFold` | Grid动画，不读取scrollHeight；收起部分inert且aria-hidden。刷新/卸载不承诺保存展开状态。 |
| `StreamText` | 仅明确新增短文本；不要用于历史正文、大体积原件或假模型流。自动响应减少动效。 |

共享代码不得导入`demoData`、`previewState`、`demoProgress`、正式API或业务状态机。样例数据、手动提交状态切换只在展示入口；Upload使用`beforeUpload=false`且无action，不读文件内容或自动外发。目标/模型/HTML内容一律按文本展示。组件库不包含业务鉴权、持久化、重放、目标访问或模型调用。

## 6. EC-1：已保存字节查看与明确复制（2026-11-11）

- 共享`EvidenceBytesViewer`与纯字节辅助函数在`web/src/ui/`，独立样式不依赖正式`ws-*`。正式HTTP正文/stdout/stderr已接入；请求/响应头复制当前遮蔽或明确展开的输出，请求正文复制现有字符串，不称线上原始报文。
- text按Unicode码点、Base64按字符、hex按源字节限制为16,384。复制与预览使用同一个值，下载为完整已保存字节；预览限制不是捕获截断。未提供字段不造0字节，显式空可下载空附件；非法Base64无伪内容或附件。未知charset/非法文本仍可查看hex/Base64并下载原件，BOM解码不称原字节保真。
- 对象`sourceKey`、材料/charset代次、显示模式变化使旧复制反馈失效；关闭/401卸载敏感子树。敏感头默认隐藏，明确展开才复制原值。不承诺撤销浏览器已接受的剪贴板写入。
- 展示页“数据与详情”使用真实共享组件和10个内存用例；同内容换记录也复位。完整请求响应/搜索/流量工作面仍仅展示，不能由该字节组件推导为已实现。
