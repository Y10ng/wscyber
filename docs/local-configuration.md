更新：2026-11-10。本文件只记录位置、非秘密参数和使用边界，**不保存明文密钥或密码**。本轮实施 G0，但不读取私有配置、不调用真实模型或操作既有服务/数据；隔离测试与真实验证见 [STATUS](STATUS.md)，历史许可不自动扩大本次范围。

## 1. 配置在哪里

| 文件 | 用途 | 保存规则 |
|---|---|---|
| 项目根目录 `.env` | 当前本机服务：数据库连接、登录令牌、运行参数 | 私有、0600、Git忽略；不复制进文档 |
| 项目根目录 `.env.example` | 可公开的配置项与默认值说明 | 无真实凭据；运行变量以此文件及 `internal/config` 为准 |
| 项目根目录 `.env.model-test` | 用户提供的独立轻量模型测试配置 | 私有、0600、Git忽略；不自动加载到应用 |

完整路径分别位于 `/root/桌面/wscyber/` 下。不得使用 `git add -f` 将私有文件纳入版本库，不在终端日志、对话或交接文档中打印它们的内容。需要使用时仅从本项目私有文件读取。

### 当前源码默认值与打包（未切换既有服务）

- `WSCYBER_SANDBOX_IMAGE=wscyber/runtime:local`；`WSCYBER_SANDBOX_NETWORK=bridge`，需要离线时显式设为 `none`。已有工具默认共享，不设逐命令审批；直连未经过平台 HTTP 风险策略或 origin 强制。
- `make image` 与 `make toolbox` 只构建同一个 runtime 镜像，使用已有 Go 缓存和前端依赖；宿主 `make run` 保留，PG 继续单独持久化。新 runtime 本轮未构建/运行；容器控制面另需 Docker CLI/socket 权限，未完成容器部署验收。
- `.env` 是显式配置，不随源码默认值改变；`scripts/init-local.py` 不覆盖既有文件。后续切换时由用户核对旧镜像/网络设置，不在本轮读取或自动迁移凭据。
