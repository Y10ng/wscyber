# 界面外壳与信息架构（U2，2026-11-19）

用户要求：左侧固定菜单 + 总览页；多栏布局分隔清楚；每个按钮有明确归属与排放逻辑。参考：上游 Cyber 控制台的布局（只看版式，未读取其数据）。本文是 U2 各片的设计依据，前端任务包按此写到尺寸级。

## 1. 信息架构

```
┌ 侧栏 240px ───────────┐┌ 页面 ───────────────────────────────────────┐
│ Logo  ·  折叠          ││ 页头：标题 · 搜索/分段 ……… 次要操作 · 主操作 │
│ 模型配置切换           ││ 筛选行：状态胶囊（带计数）                   │
│ 运营                   ││ ┌ 内容容器（圆角描边）──────────────────────┐│
│  总览                  ││ │ 表格 / 卡片                               ││
│  任务        N         ││ └───────────────────────────────────────────┘│
│  资产        N         │└──────────────────────────────────────────────┘
│  漏洞        N(红点)   │
│  报告                  │
│ 配置                   │
│  模型                  │
│  节点        在线 N    │
│ ───────────            │
│ 待审批 N（有才显示）   │
│ 原生工具图标行         │
│ 语言 · 主题 · 退出     │
└────────────────────────┘
```

- **运营**：总览 / 任务 / 资产 / 漏洞 / 报告。**配置**：模型（原生 LLM 配置）/ 节点（原生 Agent 与工具）。未实现的入口（集成、SDL）不显示（产品不变量 5）；D2 企业微信落地后再加“集成”。
- 原侧栏的会话列表取消：任务改为“任务”页表格；验证/复测/报告会话从任务内的候选/报告视图进入（S1 的归属接口继续用于标题与跳转）。非 Web/API 的普通对话会话放在任务页“类型：对话”筛选下。
- 原顶栏取消。原顶栏内容去向：新建任务 → 任务页主操作（总览页也有）；待审批 → 侧栏底部；模型切换 → 侧栏 Logo 下；`shell.header.actions` 插槽（Reflex、可观测记录、Agent、工具、设置、快速接入）→ 侧栏底部图标行；退出 → 侧栏底部。
- **任务工作区**（打开某个任务）：侧栏自动收成 56px 图标栏；工作区顶栏 = 返回（回任务页）· 任务标题 · 状态 · 资产标签 · 策略指示 · token 合计 …… 视图页签（执行 / 流量 / 候选 / 报告 / 用量，替代原左侧任务导航列）· 待审批。离开任务恢复侧栏展开状态（用户手动折叠的保持折叠）。
- URL：`?page=overview|tasks|assets|vulns|reports|models|nodes`；任务工作区沿用现有 `/sessions/<id>` 路由。刷新保持当前页。

## 2. 版式与分隔

| 元素 | 规格 |
|---|---|
| 侧栏 | 宽 240px，折叠 56px；`border-r border-border`（实线，不用 /60）；分组标题 `text-[11px] uppercase tracking-wide text-muted-foreground px-3 pt-4 pb-1`；菜单项 `h-9 rounded-md px-3 gap-2.5 text-[13px]`，选中 `bg-accent font-medium` + 左侧 2px 主色竖条；计数 `ml-auto rounded px-1.5 text-[11px] tabular-nums bg-muted` |
| 页面 | `px-6 py-5`，内容最大宽 1600px，超宽居左 |
| 页头 | 高 40px：标题 `text-[20px] font-semibold` → 搜索框（`h-9 w-[320px]`）→ 分段切换 → `ml-auto` 次要操作（outline）→ 主操作（primary，`h-9`）；页头与筛选行间距 12px |
| 筛选行 | 状态胶囊 `h-8 rounded-full px-3 text-[12px]`，选中 `border border-border bg-accent`，每个带计数与状态色点 |
| 内容容器 | `rounded-lg border border-border bg-card`；容器内标题行 `h-12 px-5 border-b border-border` |
| 表格 | 表头 `h-10 text-[12px] font-medium text-muted-foreground border-b border-border`；行 `min-h-12 border-b border-border/70`，悬停 `bg-muted/40`；数字列右对齐 `tabular-nums`；末列操作；底部分页条 `h-12 border-t` |
| 多栏 | 列表|详情、时间线|详情等并排栏之间一律 `border-l border-border`（1px 实线），每栏有自己的 `h-10` 栏头（`border-b`）；拖拽分隔条在线条上，悬停加粗为主色 |
| 卡片网格 | 总览卡片间距 16px；卡片标题行左标题、右“查看全部 →”链接 |

## 3. 按钮排放规则

1. **页面主操作**（新建任务、新建资产）：页头最右，primary，每页至多一个。
2. **页面次要操作**（刷新、导出、筛选）：主操作左侧，outline/ghost，图标+短文字；只有图标时必须有 tooltip。
3. **区块操作**：卡片/分区标题行右侧（“查看全部 →”、区块内保存）。区块内保存放在区块底部右对齐。
4. **行操作**：表格最后一列，图标按钮（打开、导出），≤3 个；破坏性操作（删除、归档）收进“…”菜单并 `confirm`。
5. **对象详情的操作**：详情顶部标题行右侧（发起测试、归档）。
6. 侧栏只放导航与全局工具，不放业务操作。
7. 同一操作在不同页面位置一致（例如“新建任务”永远是页头主按钮）。

## 4. 总览页

页头：`总览` · 时间范围分段（7 天 / 30 天 / 90 天）…… 刷新。
1. **指标行**（4 张等宽卡，高 96px）：资产（总数｜已启用计划 n）、任务（总数｜运行中 n）、漏洞（新发现+仍存在｜已修复 n，数字红色当 >0）、Token（区间合计｜日均）。点卡片跳对应页。
2. **漏洞趋势**（宽 2/3）：按日堆叠柱（新发现 / 仍存在 / 已修复，状态色 + 图例带计数）+ “查看漏洞 →”；**漏洞状态**（宽 1/3）：一条分段比例条 + 五行状态（色点 · 名称 · 数量 · 占比），参照上游任务概况卡样式。
3. **任务概况**（1/3）：分段比例条（运行中/空闲/未开始）+ 区间每日新建柱状小图；**周期计划**（1/3）：即将运行 ≤5 + 最近运行 ≤5（状态徽标）；**最近确认**（1/3）：最近 supported 的漏洞 ≤5（标题 · 资产 · 时间）。
4. **Token 用量**（整行）：区间按日柱状 + “查看用量 →”（打开现有全局用量 Dialog）。
- 无数据时各卡显示一行灰字（如“区间内没有新确认的漏洞”），不画空坐标轴。
- 不做严重度：平台目前没有严重度字段（验证、严重度、修复状态分开记录），趋势与分布按状态；以后加人工评级再扩展。

## 5. 列表页

- **任务**：页头 `任务` · 搜索 · 分段（任务 / 计划队列）…… 刷新 · **新建任务**。筛选行：全部 / 运行中 / 空闲 / 未开始 / 类型：对话。表格列：# · 创建时间 · 任务（标题 + origins 等宽小字 + 资产标签 + 计划标记）· 状态 · 候选 / 已支持 · Token · 最近活动 · 操作（打开；… 菜单：归档）。整行点击打开任务工作区。“计划队列”= 全部资产计划的即将运行 + 最近运行表。
- **资产**：沿用现有列表|详情，套页头规范（`资产` · 搜索 · 显示已归档 …… 刷新 · **新建资产**），列表与详情之间 `border-l border-border`。
- **漏洞**：页头 `漏洞` · 搜索 · 资产筛选下拉 …… 刷新。筛选行：全部 / 新发现 / 仍存在 / 待验证 / 未支持 / 已修复。表格：状态 · 标题 · 资产（或任务）· 端点（等宽）· 首次发现 · 最近确认 · 候选数 · 操作（打开：资产条目 → 资产页漏洞库并展开该条目；任务候选 → 任务候选视图）。
- **报告**：页头 `报告` · 搜索 …… 刷新。表格：报告 · 任务 · 资产 · 条目数 · 创建 · 更新 · 操作（打开、导出 MD、导出 JSON）。
